## Descripción de las APIs

El sistema consume y gestiona tres APIs diferentes para mostrar la información en su interfaz:

1. **API de Mascotas (Visor Canino HUD)**
   - **Propósito:** Gestiona y muestra información detallada sobre animales y razas caninas.
   - **Datos que maneja:** Nombre de la mascota, especie, imágenes de referencia y estado de conexión de la API (retornando respuestas en formato JSON).

2. **API de Productos (Visor de Productos)**
   - **Propósito:** Administra el catálogo de artículos comerciales e indumentaria.
   - **Datos que maneja:** Identificador del producto, nombre, categoría, precio en dólares, descripción detallada de materiales y cuidados, además de métricas de calificación y número de votos.

3. **API de Usuarios (Visor de Usuarios)**
   - **Propósito:** Administra la información de perfiles de usuario dentro del sistema.
   - **Datos que maneja:** Nombre completo, nombre de usuario (username), correo electrónico y credenciales de acceso.
